# Open-PerfectBlend

## Overview

Open-PerfectBlend is an open-sourced version of PerfectBlend.[^chengDSparkConfidenceScheduledSpeculative2026] Three papers in this wiki use it as training data for [speculative decoding](../methods/speculative-decoding.md) draft models.[^liSpecForgeFlexibleEfficient2026][^liuWhenParallelDrafter2026][^chengDSparkConfidenceScheduledSpeculative2026] None of them evaluates on it. The papers write the name as Open-PerfectBlend, Perfect-Blend, PerfectBlend, and perfect-blend.[^liSpecForgeFlexibleEfficient2026][^chengDSparkConfidenceScheduledSpeculative2026]

## Composition

- DSpark describes it as a general-purpose instruction dataset of 1.3 million samples: chat (17.6%), math (39.4%), code (38.9%), and instruction-following data (4.1%).[^chengDSparkConfidenceScheduledSpeculative2026]
- SpecForge describes it as 1.4M conversations in the chat, math, coding, and instruction-following domains.[^liSpecForgeFlexibleEfficient2026]

## Usage across papers

| Paper | What it is used for | Models / setting | Reported numbers |
|---|---|---|---|
| [SpecForge](../papers/liSpecForgeFlexibleEfficient2026.md) | Training set for the SpecBundle EAGLE3 draft models. Assistant responses are regenerated by the target model with temperature 0.8, and drafts are trained from scratch for 2 epochs | Seven target models | For LLaMA-3.1-Instruct, acceptance length on Math500 is 3.48 with Perfect-Blend against 2.82 with ShareGPT and UltraChat, an additional 1.17× inference speedup[^liSpecForgeFlexibleEfficient2026] |
| [DSpark](../papers/chengDSparkConfidenceScheduledSpeculative2026.md) | Prompts only, for training the DSpark, DFlash, and Eagle3 drafters. Responses are regenerated by each target model, and each drafter is trained for 10 epochs | Qwen3-4B, 8B, 14B and Gemma4-12B | No number is reported on the dataset itself[^chengDSparkConfidenceScheduledSpeculative2026] |
| [DPara](../papers/liuWhenParallelDrafter2026.md) | Prompts for the shared training set of the M-DFlash backbones, with responses generated by Qwen3-8B | Qwen3-8B and 14B | No number is reported on the dataset itself[^liuWhenParallelDrafter2026] |

### [SpecForge](../papers/liSpecForgeFlexibleEfficient2026.md): regenerating the responses

SpecForge trains an EAGLE3 draft for LLaMA-3.1-8B on the original PerfectBlend data and on a version with regenerated responses. Regeneration increases the acceptance length on nearly all benchmarks, with FinanceQA the only exception, and gives an average throughput improvement of 5.3% across all benchmarks.[^liSpecForgeFlexibleEfficient2026] Its TTT-length sweep on Llama3.1-8B also uses this dataset.[^liSpecForgeFlexibleEfficient2026]

# Contradictions

### Dataset size

DSpark gives Open-PerfectBlend as 1.3 million samples.[^chengDSparkConfidenceScheduledSpeculative2026] SpecForge gives it as 1.4M conversations.[^liSpecForgeFlexibleEfficient2026] Both describe the same four domains. Neither paper states a dataset version or a filtering step, and the units differ ("samples" and "conversations").
