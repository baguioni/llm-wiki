# Multi-Session Chat (MSC)

## Overview

The Multi-Session Chat (MSC) dataset contains multi-session chat logs generated by human labelers, each of whom was asked to play a consistent persona for the duration of all sessions.[^packerMemGPTLLMsOperating2024] [MemGPT](../methods/memgpt.md) expands it and builds two dialogue tasks on it: deep memory retrieval (DMR) and conversation opener.[^packerMemGPTLLMsOperating2024] Zep evaluates on the DMR task.[^rasmussenZepTemporalKnowledge2025]

## Composition

- Each multi-session chat has five total sessions, and each session consists of roughly a dozen messages.[^packerMemGPTLLMsOperating2024]
- The dataset has gold persona labels, which effectively summarize the knowledge accumulated throughout all prior sessions.[^packerMemGPTLLMsOperating2024]
- MemGPT's augmentation: a new session (session 6) that contains a single question-answer response pair between the same two personas. The question-answer pairs were generated by a separate LLM from the original MSC dataset. The augmented MSC dataset is publicly released.[^packerMemGPTLLMsOperating2024]
- The DMR evaluation, as Zep describes it, uses a 500-conversation subset of MSC. Each conversation contains 5 chat sessions with up to 12 messages per session, and includes a question/answer pair.[^rasmussenZepTemporalKnowledge2025]
- Each DMR conversation contains only 60 messages.[^rasmussenZepTemporalKnowledge2025]

### Protocols

- In DMR, the user asks a question that explicitly refers back to a prior conversation and has a very narrow expected answer range. Responses are scored with ROUGE-L recall and with an LLM judge that checks consistency with the gold response.[^packerMemGPTLLMsOperating2024]
- MemGPT's baselines see a lossy summarization of the past five conversations. MemGPT has access to the full conversation history but must reach it through paginated search queries.[^packerMemGPTLLMsOperating2024]
- In the conversation opener task, the generated opener is compared to the gold personas (SIM-1/3) and to the human-created opener (SIM-H), the first response in the following session.[^packerMemGPTLLMsOperating2024]
- Zep ingests the conversations and retrieves the top 10 most relevant nodes and edges with its search functions. An LLM judge compares the responses to the golden answers.[^rasmussenZepTemporalKnowledge2025]

## Known issues

- Zep's authors note that each DMR conversation fits easily within current LLM context windows, and their full-conversation baseline scores 94.4% with gpt-4-turbo, above MemGPT's 93.4%.[^rasmussenZepTemporalKnowledge2025]
- Zep's authors could not reproduce MemGPT's results with gpt-4o-mini, citing insufficient methodological details in the published work.[^rasmussenZepTemporalKnowledge2025]
- MemGPT describes a session as roughly a dozen messages,[^packerMemGPTLLMsOperating2024] and Zep describes it as up to 12 messages.[^rasmussenZepTemporalKnowledge2025]
