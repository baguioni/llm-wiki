# Research Wiki

## Papers

* [Agent World Model: Infinity Synthetic Environments for Agentic Reinforcement Learning](papers/wangAgentWorldModel2026.md) - Open-source pipeline that synthesizes 1,000 code-driven, SQLite-backed, MCP-exposed tool-use environments with verification code, used to train Qwen3 agents with GRPO that generalize to out-of-distribution benchmarks.
* [Agent-RLVR: Training Software Engineering Agents via Guidance and Environment Rewards](papers/daAgentRLVRTrainingSoftware2025.md) - RLVR training framework for software engineering agents that has the agent reattempt failed tasks with teacher-generated guidance and then updates the policy with offline DPO on unit-test rewards.
* [AgentDropout: Dynamic Agent Elimination for Token-Efficient and High-Performance LLM-Based Multi-Agent Collaboration](papers/wangAgentDropoutDynamicAgent2025.md) - Topology optimization for LLM multi-agent systems that learns communication-graph adjacency matrices, then drops low-contribution agents per round (Node Dropout) and low-weight edges (Edge Dropout) to cut tokens and raise accuracy.
* [AgentScope: A Flexible yet Robust Multi-Agent Platform](papers/gaoAgentScopeFlexibleRobust2024.md) - Developer-centric multi-agent platform built on message exchange, with fault tolerance, multi-modal, tool, and RAG support, and an actor-based distributed mode.
* [Autellix: An Efficient Serving Engine for LLM Agents as General Programs](papers/luoAutellixEfficientServing.md) - LLM serving system that schedules LLM calls by the attained service of their parent agentic program (PLAS, ATLAS) and routes calls across engines by program data locality.
* [Collaborative Speculative Inference for Efficient LLM Inference Serving](papers/gaoCollaborativeSpeculativeInference.md) - CoSine decouples speculative drafting from verification across heterogeneous nodes, with drafter routing, confidence-based token fusion, and pipeline scheduling.
* [Compact Language Models via Pruning and Knowledge Distillation](papers/muralidharanCompactLanguageModels2024.md) - Empirical study of structured pruning (depth, width, attention, MLP) plus distillation-based retraining that yields a list of compression best practices and the Minitron 8B and 4B models derived from Nemotron-4 15B.
* [Decoding Speculative Decoding](papers/yanDecodingSpeculativeDecoding2025.md) - Empirical study showing that speculative decoding throughput is bottlenecked by draft model latency and depth, and that wide, shallow pruned draft models give up to 111% higher throughput.
* [DFlash: Block Diffusion for Flash Speculative Decoding](papers/chenDFlashBlockDiffusion2026.md) - Speculative decoding framework whose drafter is a lightweight block diffusion model, conditioned on target hidden features through KV injection, that drafts a whole token block in one forward pass.
* [DistillSpec: Improving Speculative Decoding via Knowledge Distillation](papers/zhouDistillSpecImprovingSpeculative2024.md) - Uses white-box knowledge distillation with on-policy draft-generated data and a task-tuned divergence to align the draft model with the target model and raise speculative decoding speed.
* [DSpark: Confidence-Scheduled Speculative Decoding with Semi-Autoregressive Generation](papers/chengDSparkConfidenceScheduledSpeculative2026.md) - Speculative decoding framework that adds a lightweight sequential head to a parallel drafter and schedules per-request verification length from calibrated confidence and engine load, deployed in the DeepSeek-V4 serving system.
* [DualPath: Breaking the Storage Bandwidth Bottleneck in Agentic LLM Inference](papers/wuDualPathBreakingStorage2026.md) - Inference system for agentic workloads that loads KV-Cache through decode engines as well as prefill engines, pooling the storage NIC bandwidth of all engines in a prefill-decode disaggregated cluster.
* [EAGLE-3: Scaling up Inference Acceleration of Large Language Models via Training-Time Test](papers/liEAGLE3ScalingInference2025.md) - Speculative sampling draft model that drops EAGLE's feature prediction for direct token prediction with training-time test and fuses low-, mid-, and high-level target features.
* [Efficient On-Device Diffusion LLM Inference with Mobile NPU](papers/wangEfficientOnDeviceDiffusion2026.md) - llada.cpp, an NPU-aware inference framework that speeds up block-wise diffusion LLM generation on smartphones with multi-block speculative decoding, dual-path progressive revision, and a swap-optimized memory runtime.
* [Idleness Is Relative: Exploiting Tool-Call Idle Windows for Offloading in Agentic Systems with MORI](papers/xiaIdlenessRelativeExploiting2026.md) - MORI is an agent serving scheduler that ranks programs by a continuous idleness metric and places their KV caches across GPU HBM and CPU DRAM with admission control at both tiers.
* [InferCept: Efficient Intercept Support for Augmented Large Language Model Inference](papers/abhyankarInferCeptEfficientIntercept2024.md) - LLM inference framework that handles tool, model, and human interceptions by choosing preserve, discard, or swap per request to minimize GPU memory waste.
* [Is Your NPU Ready for LLMs? Dissecting the Hidden Efficiency Bottlenecks in Mobile LLM Inference](papers/caiYourNPUReady2026.md) - Cross-layer measurement study of mobile LLM inference across five frameworks and CPU, GPU, and NPU backends, with a backend-level energy profiler (PowerBench) and an energy-oriented NPU configuration.
* [KAIROS: Stateful, Context-Aware Power-Efficient Agentic Inference Serving](papers/yuanKAIROSStatefulContextAware2026.md) - Power management system for agentic LLM serving that uses aggregate agent context as the control signal for GPU frequency, per-instance concurrency, and multi-instance routing, cutting average GPU power by 27% while meeting a per-agent throughput SLO.
* [Learning To Draft: Adaptive Speculative Decoding with Reinforcement Learning](papers/zhangLearningDraftAdaptive2026.md) - Trains two co-adaptive reinforcement learning policies, one for draft tree depth and one for verification size, with per-cycle throughput as the reward, on top of Eagle3.
* [Leyline: KV Cache Directives for Agentic Inference](papers/maLeylineKVCache2026.md) - Serving-side primitive that lets an agent policy issue (span, replacement) directives to splice the KV cache in place, using a closed-form RoPE delta-rotation on MLA models so the unchanged prefix and downstream slots are not re-prefilled.
* [LK Losses: Direct Acceptance Rate Optimization for Speculative Decoding](papers/samarinLKLossesDirect2026.md) - Training objectives for speculative decoding draft models that optimize the acceptance rate directly, as a negative log-acceptance loss or an adaptively blended KL and total variation loss.
* [MemGPT: Towards LLMs as Operating Systems](papers/packerMemGPTLLMsOperating2024.md) - OS-inspired LLM system that uses function calls to page information between the context window and external storage, giving a fixed-context LLM the illusion of extended context.
* [Parrot: Efficient Serving of LLM-based Applications with Semantic Variable](papers/linParrotEfficientServing2024.md) - LLM service system that exposes application-level knowledge through the Semantic Variable abstraction so the service can analyze request dependencies and shared prompts and optimize end-to-end application performance.
* [R2E-Gym: Procedural Environments and Hybrid Verifiers for Scaling Open-Weights SWE Agents](papers/jainR2EGymProceduralEnvironments2025.md) - Procedurally curated gym of more than 8.1K executable SWE tasks built from commits (SweGen), plus a hybrid execution-based and execution-free verifier that reaches 51% on SWE-Bench Verified with a 32B open-weight model.
* [Reflexion: Language Agents with Verbal Reinforcement Learning](papers/shinnReflexionLanguageAgents2023.md) - Framework that reinforces LLM agents without weight updates by having them write verbal self-reflections on task feedback and keep them in an episodic memory buffer for later trials.
* [Safe and Scalable Web Agent Learning via Recreated Websites](papers/chaeSafeScalableWeb2026.md) - VeriEnv uses a coding agent to clone real websites into executable synthetic environments with a Python SDK, so web agents can train on self-generated tasks with deterministic, programmatically verified rewards.
* [SAGA: Workflow-Atomic Scheduling for AI Agent Inference on GPU Clusters](papers/guoSAGAWorkflowAtomicScheduling2026.md) - Distributed scheduler that treats a whole agent workflow as the schedulable unit, with workflow-aware KV cache eviction, session-affinity batching, and task-level fairness.
* [SDFP: Speculative Decoding with FIT-Pruned Models for Training-Free and Plug-and-Play LLM Acceleration](papers/weiSDFPSpeculativeDecoding2026.md) - Training-free speculative decoding that builds the draft model by pruning the target LLM's least sensitive layers, ranked by Fisher Information Trace computed on WikiText2.
* [SGLang: Efficient Execution of Structured Language Model Programs](papers/zhengSGLangEfficientExecution2024.md) - A Python-embedded language and co-designed runtime for multi-call LLM programs that reuses the KV cache through a radix tree (RadixAttention) and speeds up constrained decoding with a compressed finite state machine.
* [Sheared LLaMA: Accelerating Language Model Pre-Training via Structured Pruning](papers/xiaShearedLLaMAAccelerating2024.md) - LLM-shearing prunes LLaMA2-7B to a pre-specified 1.3B or 2.7B architecture and continues pre-training with dynamic batch loading, using 50B tokens.
* [SpecEdge: Scalable Edge-Assisted Serving Framework for Interactive LLMs](papers/parkSpecEdgeScalableEdgeAssisted2025.md) - Edge-assisted LLM serving framework that splits speculative decoding into drafting on consumer-grade edge GPUs and verification on server GPUs, with proactive edge drafting and pipeline-aware server scheduling.
* [SpecExec: Massively Parallel Speculative Decoding for Interactive LLM Inference on Consumer Devices](papers/svirschevskiSpecExecMassivelyParallel2024.md) - Speculative decoding method that builds a large deterministic draft tree with a parallel shortest-path search and validates it as a cache in one offloaded target-model pass, for running 50B+ models on consumer GPUs.
* [SpecForge: A Flexible and Efficient Open-Source Training Framework for Speculative Decoding](papers/liSpecForgeFlexibleEfficient2026.md) - Open-source framework for training EAGLE-3 draft models that decouples the target model (run on SGLang) from the draft model (trained with ZeRO Stage 2), released with the SpecBundle suite of draft models.
* [Speculative Speculative Decoding](papers/kumarSpeculativeSpeculativeDecoding2026.md) - Framework (SSD) and optimized algorithm (Saguaro) that run drafting in parallel with verification by pre-speculating for predicted verification outcomes on a separate device.
* [SuffixDecoding: Extreme Speculative Decoding for Emerging AI Applications](papers/oliaroSuffixDecodingExtremeSpeculative2024.md) - Model-free speculative decoding that drafts tokens from suffix trees over the current request and prior outputs, with speculation length adapted to the pattern match length, aimed at repetitive agentic workloads.
* [SWE-agent: Agent-Computer Interfaces Enable Automated Software Engineering](papers/yangSWEagentAgentComputerInterfaces2024.md) - Introduces the agent-computer interface (ACI) and SWE-agent, an LM agent whose custom file viewer, editor, search, and context management commands resolve 12.47% of SWE-bench with GPT-4 Turbo.
* [SWE-RL: Advancing LLM Reasoning via Reinforcement Learning on Open Software Evolution](papers/weiSWERLAdvancingLLM2025.md) - Reinforcement learning on GitHub pull-request data with a patch-similarity reward that trains Llama3-SWE-RL-70B to a 41.0% solve rate on SWE-bench Verified.
* [SWE-RM: Execution-Free Feedback for Software Engineering Agents](papers/shumSWERMExecutionfreeFeedback2025.md) - Execution-free reward model for software engineering agents, trained for ranking, discrimination (AUC), and calibration (ECE) so that it works for both test-time scaling and reinforcement learning.
* [SYMPHONY: Improving Memory Management for LLM Inference Workloads](papers/agarwalSYMPHONYImprovingMemory2024.md) - Cluster-level LLM serving system that uses advisory requests from multi-turn workloads to prefetch and migrate K,V caches off the critical path, enabling request-level load balancing.
* [The Synergy of Speculative Decoding and Batching in Serving Large Language Models](papers/suSynergySpeculativeDecoding2023.md) - Characterization of batched speculative decoding showing that the optimal speculation length shrinks as batch size grows, with an adaptive scheme that picks the speculation length per batch size from a profiled look-up table.
* [ThunderAgent: A Simple, Fast and Program-Aware Agentic Inference System](papers/kangThunderAgentSimpleFast2026.md) - Agentic inference system that schedules whole agent workflows as programs, pausing and migrating them to avoid KV cache thrashing and cross-node memory imbalance, and manages tool environments by program lifecycle.
* [VOYAGER: An Open-Ended Embodied Agent with Large Language Models](papers/wangVOYAGEROpenEndedEmbodied.md) - LLM-powered embodied lifelong learning agent for Minecraft that combines an automatic curriculum, a skill library of executable code, and iterative prompting with self-verification, using blackbox GPT-4 queries.
* [Wan: Open and Advanced Large-Scale Video Generative Models](papers/wanWanOpenAdvanced2025.md) - Open suite of diffusion-transformer video foundation models (1.3B and 14B) with a 3D causal VAE, a data and training pipeline, the Wan-Bench evaluation, and downstream image-to-video, editing, personalization, real-time, and audio models.
* [WebArena: A Realistic Web Environment for Building Autonomous Agents](papers/zhouWebArenaRealisticWeb2024.md) - A standalone, self-hostable web environment of fully functional websites with an 812-task benchmark that scores web agents by the functional correctness of task completion.
* [Weblica: Scalable and Reproducible Training Environments for Visual Web Agents](papers/karWeblicaScalableReproducible2026.md) - Framework that builds offline web training environments by HTTP-level caching of real sites and LLM-based synthesis of new sites, used to train screenshot-only web agents with SFT followed by RL.
* [WebRL: Training LLM Web Agents via Self-Evolving Online Curriculum Reinforcement Learning](papers/qiWebRLTrainingLLM2025.md) - Online curriculum reinforcement learning framework that trains open LLMs into web agents using self-generated tasks, a learned outcome reward model, and a KL-constrained off-policy update.
* [WebSailor-V2: Bridging the Chasm to Proprietary Agents via Synthetic Data and Scalable Reinforcement Learning](papers/liWebSailorV2BridgingChasm2025.md) - Post-training pipeline for an open-source web agent that combines the SailorFog-QA-V2 synthetic dataset, an SFT cold start, and GRPO-based RL in simulated and real environments on Qwen3-30B-A3B.
* [When Parallel Drafter Meets Parallel Speculative Decoding](papers/liuWhenParallelDrafter2026.md) - DPara is a parallel speculative decoding framework that precomputes a diffusion drafter backbone for every acceptance boundary during verification, so only a lightweight autoregressive head stays on the critical path and no serial fallback occurs.
* [When RL Meets Adaptive Speculative Training: A Unified Training-Serving System](papers/wangWhenRLMeets2026.md) - Aurora, a unified training-serving system that trains a speculative-decoding draft model online from live inference traces as an asynchronous RL problem and hot-swaps updates into an SGLang server.
* [Zep: A Temporal Knowledge Graph Architecture for Agent Memory](papers/rasmussenZepTemporalKnowledge2025.md) - Agent memory layer built on Graphiti, a temporally-aware knowledge graph engine with episodic, semantic entity, and community subgraphs and hybrid graph retrieval.

## Methods

* [Agentless](methods/agentless.md) - Pipeline-based, non-agent scaffold for SWE-bench issue resolution with localization, repair, and test-based patch selection steps, used as a baseline scaffold and as a base for simplified variants.
* [AutoGen](methods/autogen.md) - Multi-agent conversation framework that papers in this wiki cite as a source of agent workflows and as an example of a dynamic multi-agent workload for LLM serving.
* [Chain-of-Thought Prompting](methods/chain-of-thought.md) - Prompting strategy in which the model writes step-by-step reasoning before its answer or action, used in this wiki's papers as an agent component and as a single-agent baseline.
* [Chunked prefill](methods/chunked-prefill.md) - Technique that splits a prompt's prefill into chunks so that each chunk shares a batch with decoding requests, as the wiki's papers describe and use it.
* [Continuous batching](methods/continuous-batching.md) - Batching scheme for LLM serving in which requests join and leave the running batch between forward passes, as the wiki's papers describe and rely on it.
* [DFlash](methods/dflash.md) - Speculative decoding drafter that uses a lightweight block diffusion model, conditioned on target hidden features through KV injection, to draft a whole token block in one forward pass.
* [DistillSpec](methods/distillspec.md) - White-box knowledge distillation of the draft model toward the target model, with on-policy draft-generated data and a task-tuned divergence, to raise the acceptance rate of speculative decoding.
* [DPO](methods/dpo.md) - Policy optimization from pairs of winning and losing responses to the same input, which avoids explicitly modeling the reward and is used offline by Agent-RLVR.
* [DSpark](methods/dspark.md) - Speculative decoding framework that adds a lightweight sequential head to a parallel DFlash-style drafter and schedules per-request verification length from calibrated confidence and engine load.
* [DVFS (Dynamic Voltage and Frequency Scaling)](methods/dvfs.md) - Changing the operating frequency or voltage point of a CPU, GPU, or NPU to trade inference speed for power, studied in this wiki for mobile LLM inference and for agentic LLM serving on GPUs.
* [EAGLE](methods/eagle.md) - Speculative sampling method whose draft model performs autoregression at the feature level, reusing the target model's top-layer features and LM head; predecessor of EAGLE-2 and EAGLE-3.
* [EAGLE-2](methods/eagle-2.md) - Successor of EAGLE that builds a context-aware dynamic draft tree from the draft model's confidence; the direct baseline of EAGLE-3.
* [EAGLE-3](methods/eagle-3.md) - Speculative sampling draft model that predicts tokens directly from fused low-, mid-, and high-level target features and is trained with training-time test; the most re-measured baseline among the wiki's speculative decoding papers.
* [Execution-free verifier](methods/execution-free-verifier.md) - A trained model that scores an agent trajectory or patch for correctness without running code, used to select among candidates at test time and as a reward signal in RL.
* [GRPO](methods/grpo.md) - Group Relative Policy Optimization, a policy-gradient RL objective that samples a group of rollouts per prompt and uses each rollout's reward relative to its group as the advantage.
* [Knowledge Distillation](methods/knowledge-distillation.md) - Training a smaller student model under the supervision of a larger teacher model, used in this wiki to retrain pruned LLMs and to align speculative-decoding draft models with their targets.
* [KV cache](methods/kv-cache.md) - The per-token key and value tensors that an LLM keeps from earlier tokens so that later tokens do not recompute them, and the object that most serving papers in the wiki manage, share, move, or shrink.
* [KV cache offloading](methods/kv-cache-offloading.md) - Moving KV cache that is not immediately needed from GPU HBM to CPU DRAM or lower storage tiers and reloading it on demand, to extend the effective KV cache capacity of a serving node.
* [KV cache swapping](methods/kv-cache-swapping.md) - Moving a paused request's KV cache from GPU memory to CPU memory and back, so that the context is neither recomputed nor left idle on the GPU.
* [KV injection](methods/kv-injection.md) - Conditioning mechanism from DFlash that injects fused target-model hidden features into the Key and Value projections of every draft layer instead of feeding them only as drafter inputs.
* [LangChain](methods/langchain.md) - LLM orchestration framework for composing LLM calls and tools into applications, which papers in this wiki use as the application layer above serving systems and as a baseline client.
* [llama.cpp](methods/llama-cpp.md) - An open-source, community-maintained LLM inference framework in C/C++ that the wiki's papers measure on mobile CPU, GPU, and NPU backends and extend for on-device diffusion LLM inference.
* [LLM-as-a-Judge](methods/llm-as-a-judge.md) - Use of an LLM to decide whether an agent trajectory or output is correct, applied in this wiki's papers as a training reward and as an evaluation metric, and contrasted with executable, deterministic verification.
* [LLM-Pruner](methods/llm-pruner.md) - A structured pruning method for LLMs that the wiki's papers use only as a comparison baseline for Sheared-LLaMA and Minitron.
* [LMCache](methods/lmcache.md) - KV cache storage and movement layer for vLLM and SGLang that operates on cache blocks in physical storage tiers, used by papers in this wiki as an offloading baseline and as the layer below semantic cache edits.
* [Medusa](methods/medusa.md) - Speculative decoding approach that attaches extra decoding heads to the target model, which predict several draft tokens in parallel from the same hidden state without a separate draft model.
* [MemGPT](methods/memgpt.md) - OS-inspired LLM system that uses function calls to page information between a fixed context window and external storage, a technique its authors call virtual context management.
* [MetaGPT](methods/metagpt.md) - Multi-agent framework that assigns software-development roles to LLMs, used by LLM serving papers in this wiki as a multi-agent programming workload.
* [Multi-Token Prediction (MTP)](methods/multi-token-prediction.md) - A module that ships with the target model (DeepSeek-V3, DeepSeek-V4, Qwen3.5 in the wiki's papers) and predicts tokens beyond the next one, reused as the drafter for speculative decoding.
* [OpenHands](methods/openhands.md) - Open-source coding agent scaffold that runs a model in a sandbox over multiple turns, used in the wiki's papers as an SWE-bench agent, a rollout scaffold for training, and a serving workload.
* [PagedAttention](methods/paged-attention.md) - Memory management technique from vLLM that stores the KV cache in non-contiguous blocks tracked by a per-request page table, as the wiki's papers describe and reuse it.
* [PEARL](methods/pearl.md) - Parallel speculative decoding method that drafts the next round during ongoing verification, preparing only for the outcome in which all draft tokens are accepted.
* [Prefix caching](methods/prefix-caching.md) - Reuse of the KV cache of a shared prompt prefix across LLM requests, so that the prefill of the prefix is not recomputed.
* [Program-aware scheduling](methods/program-aware-scheduling.md) - Scheduling LLM serving at the level of the agentic program (all model invocations and tool calls of one agent workflow) instead of the individual request.
* [RadixAttention](methods/radix-attention.md) - SGLang's technique for automatic KV cache reuse, which keeps the cache of all requests as an LRU cache in a radix tree and schedules requests by matched prefix length.
* [ReAct](methods/react.md) - Agent loop in which an LLM alternates a reasoning trace (thought), an action, and the observation returned by the environment, used as the base scaffold or baseline by many agent papers in this wiki.
* [Reflexion](methods/reflexion.md) - Verbal reinforcement framework in which an LLM agent writes self-reflections on task feedback and keeps them in an episodic memory that conditions its next trial, with no weight updates.
* [Retrieval-Augmented Generation](methods/retrieval-augmented-generation.md) - Approach that retrieves relevant external documents and inserts them into the LLM prompt before generation, used in this wiki's papers as a framework module, a non-interactive baseline, and the starting point for agent memory systems.
* [Sequoia](methods/sequoia.md) - Tree-based speculative decoding method that the wiki's papers describe as using fixed (static) draft tree structures and pruning unpromising branches, used as a comparison point and as a source of tree construction.
* [SGLang](methods/sglang.md) - Language and serving runtime for LLM programs that reuses the KV cache through RadixAttention, and that later papers use as a baseline, a host engine, or a deployment target.
* [Sheared-LLaMA](methods/sheared-llama.md) - LLM-shearing prunes LLaMA2-7B to a pre-specified 1.3B or 2.7B architecture with targeted structured pruning and continues pre-training with dynamic batch loading; the name covers both the method and the resulting models.
* [SpecExec](methods/specexec.md) - Speculative decoding method that deterministically builds a large draft tree of the most probable continuations with a parallel shortest-path search and validates it as a cache in one target-model pass.
* [SpecInfer](methods/specinfer.md) - Speculative inference system with tree-structured drafts and token tree verification, used by the wiki's papers as a baseline and as a reference setup.
* [Speculative Decoding](methods/speculative-decoding.md) - Lossless LLM inference acceleration in which a cheap drafter proposes several tokens and the target model verifies them in one parallel pass; hub page for the 17 papers in this wiki that change the drafter, the verification, the training, the system, or the deployment.
* [Speculative Speculative Decoding (SSD)](methods/speculative-speculative-decoding.md) - Framework that runs drafting in parallel with verification by pre-speculating, on a separate device, for a set of predicted verification outcomes held in a speculation cache.
* [Structured Pruning](methods/structured-pruning.md) - Model compression that removes whole groups of parameters (layers, attention heads, neurons, embedding channels) so that the result is a smaller dense model, usually followed by retraining.
* [SWE-agent](methods/swe-agent.md) - LM agent for software engineering that pairs a language model with an agent-computer interface of custom file viewing, search, and editing commands, and solves 12.47% of SWE-bench with GPT-4 Turbo.
* [Test-time scaling](methods/test-time-scaling.md) - Spending more compute at inference, by sampling several attempts and selecting one with a verifier or counting any success, to raise an agent's task success rate.
* [ThunderAgent](methods/thunderagent.md) - Agentic inference system that schedules whole agent workflows as programs, pausing and restoring them by execution phase and context length to avoid KV cache thrashing, with a global waiting queue across GPU nodes and lifecycle-aware tool resource management.
* [Training-Time Test](methods/training-time-test.md) - Draft-model training technique from EAGLE-3 that simulates multi-step drafting during training by feeding the draft model's own outputs back as inputs, so the draft adapts to self-generated inputs.
* [Tree-based speculation](methods/tree-based-speculation.md) - Family of speculative decoding methods in which the drafter proposes a tree of candidate tokens, giving the verifier several options per position, and the target verifies the whole tree in one pass.
* [vLLM](methods/vllm.md) - LLM inference engine that the wiki's papers use as a baseline, as the system they extend, or as the serving host for their experiments.

## Datasets

* [ALFWorld](datasets/alfworld.md) - Suite of text-based interactive environments for multi-step household tasks, used in the wiki's papers to test agent decision-making and to generate an agent serving workload.
* [Alpaca](datasets/alpaca.md) - Instruction-following prompt set that the wiki's speculative-decoding papers use for measuring speedup and acceptance length.
* [C4](datasets/c4.md) - Text corpus used in the wiki's papers as a prompt source for speculative decoding speed tests, and one of the seven domains of RedPajama.
* [Chatbot Instruction Prompts](datasets/chatbot-instruction-prompts.md) - Huggingface dataset of general assistant-style prompts that two of the wiki's papers use as an input stream for speculative-decoding serving experiments.
* [CNN/Daily Mail](datasets/cnn-dailymail.md) - News summarization dataset, used in the wiki's papers as the summarization workload for measuring speculative decoding speedup.
* [GSM8K](datasets/gsm8k.md) - Grade-school math word problem dataset that the wiki's papers use as a math prompt set for speculative-decoding speed measurements and as a math accuracy test.
* [HellaSwag](datasets/hellaswag.md) - Commonsense completion dataset, used in the wiki's papers as an accuracy test for compressed and on-device models and as a prompt source for speed measurements.
* [HotpotQA](datasets/hotpotqa.md) - Wikipedia-based multi-hop question answering dataset, used in the wiki's papers to test agent reasoning and to generate agent serving workloads.
* [HumanEval](datasets/humaneval.md) - Code generation benchmark that the wiki's papers use as a coding prompt set for speculative-decoding speed measurements and as a pass@1 accuracy test.
* [LiveCodeBench](datasets/livecodebench.md) - Code benchmark that the wiki's speculative-decoding papers use as a coding prompt set for measuring speedup and acceptance length.
* [MATH-500](datasets/math-500.md) - Math problem set that the wiki's speculative-decoding papers use as a prompt set for measuring speedup and acceptance length.
* [MBPP](datasets/mbpp.md) - Code generation benchmark used in the wiki's papers as a coding prompt set for speculative-decoding speed measurements and as a pass@1 accuracy test.
* [MMLU](datasets/mmlu.md) - Multiple-choice benchmark with 57 subtasks, used in the wiki's papers as an accuracy test for compressed, agentic, and fine-tuned LLMs and as a prompt source for speed measurements.
* [MT-Bench](datasets/mt-bench.md) - Multi-turn conversation benchmark that the wiki's papers use mostly as a chat prompt set for speculative-decoding speed measurements, and once as a quality score.
* [Multi-Session Chat](datasets/multi-session-chat.md) - Dataset of multi-session, persona-consistent chat logs written by human labelers, which MemGPT extends into the deep memory retrieval and conversation opener tasks.
* [Open-PerfectBlend](datasets/perfectblend.md) - Mixed chat, math, code, and instruction-following conversation dataset that the wiki's papers use to train speculative-decoding draft models.
* [R2E-Gym](datasets/r2e-gym.md) - Procedurally curated gym of 8,135 executable software engineering tasks built from GitHub commits with generated tests and back-translated issues, used to train SWE agents and verifiers.
* [RedPajama](datasets/redpajama.md) - Replicated pre-training dataset of the LLaMA1 models with seven domains, used in the wiki's papers as the data for structured pruning and continued pre-training.
* [ShareGPT](datasets/sharegpt.md) - Dataset of real user conversations with ChatGPT, used in the wiki's papers as a chatbot serving trace and as training data for draft models and instruction tuning.
* [Spider](datasets/spider.md) - Text-to-SQL dataset that two of the wiki's papers use as a structured-output workload for speculative-decoding experiments under distribution shift.
* [SWE-Gym](datasets/swe-gym.md) - Training environment of executable GitHub issue-resolution tasks with human-written issues and tests, used in the wiki's papers as a training source, a baseline model family, and a verifier baseline.
* [WikiText-2](datasets/wikitext-2.md) - Text dataset used in the wiki's papers as a prompt source for speculative decoding speed tests, as a perplexity test set for quantization, and as a calibration set for layer pruning.
* [XSum](datasets/xsum.md) - Extreme Summarization dataset of BBC news articles, used in the wiki's papers to measure speculative decoding speedup and ROUGE-2.

## Benchmarks

* [Berkeley Function Calling Leaderboard (BFCL)](benchmarks/bfcl.md) - Function-calling benchmark for LLMs, reported in the wiki as BFCL v2 and BFCLv3, and also used as a ReAct agent workload for serving systems.
* [Deep Memory Retrieval (DMR)](benchmarks/deep-memory-retrieval.md) - Conversational memory task built on Multi-Session Chat, in which an agent answers a question that refers back to prior chat sessions and is scored by an LLM judge.
* [Humanity's Last Exam (HLE)](benchmarks/hle.md) - Expert-written question benchmark that the wiki's papers use to test deep academic and logical reasoning of web agents and as a tool-heavy serving workload.
* [Online-Mind2Web](benchmarks/online-mind2web.md) - Web navigation benchmark that evaluates agents on live websites with an LLM-as-judge for task success, also called Mind2Web-Online.
* [Spec-Bench](benchmarks/spec-bench.md) - Benchmark and codebase for comparing speculative decoding methods by speedup over vanilla decoding across 13 task categories.
* [SWE-bench](benchmarks/swe-bench.md) - Benchmark of 2,294 GitHub-issue resolution tasks from 12 Python repositories, scored by the share of issues whose tests pass after the generated patch is applied.
* [SWE-bench Lite](benchmarks/swe-bench-lite.md) - Canonical 300-instance subset of the SWE-bench test set focused on self-contained functional bug fixes, used for ablations, small-model comparisons, and as a serving workload.
* [SWE-bench Verified](benchmarks/swe-bench-verified.md) - Human-verified 500-problem subset of SWE-bench for resolving real GitHub issues, reported in this wiki at rollout budgets from greedy pass@1 to reranking over 500 patches.
* [Terminal-Bench](benchmarks/terminal-bench.md) - Benchmark of realistic, human-verified command-line tasks, used in this wiki as an out-of-domain check for RL-trained coding agents and as an agentic serving workload.
* [WebArena](benchmarks/webarena.md) - Self-hosted web environment with 812 long-horizon tasks that scores web agents by the functional correctness of task completion.
* [WebArena-Lite](benchmarks/webarena-lite.md) - Human-verified subset of WebArena with 165 test cases, used to compare trained open-model web agents and proprietary LLM agents by task success rate.
* [WebShop](benchmarks/webshop.md) - Web-based problem-solving benchmark in which an agent navigates an e-commerce website to locate and purchase products given requests from clients.

## Results

* [Discarding context at interceptions costs 37-40% of model forwarding time](results/recomputation-share-of-forwarding-time.md) - InferCept measures that recomputing discarded context takes 37-40% of total model forwarding time on a mixed augmented-LLM workload.
* [Speculative decoding speedup falls from 2.73× to 1.31× as batch size grows from 1 to 32](results/speculative-decoding-speedup-vs-batch-size.md) - Su et al. measure that the speedup of speculative decoding shrinks as batch size grows and that the best speculation length gets shorter.
* [Test-time scaling with a verifier raises SWE-bench Verified scores above single-attempt scores](results/swe-bench-verified-test-time-scaling.md) - R2E-Gym and SWE-RM both report large gains on SWE-bench Verified from selecting among many rollouts with a verifier.
* [WebRL lifts open models to 42.4-49.1 average success rate on WebArena-Lite](results/webrl-webarena-lite.md) - WebRL trains Llama3.1 and GLM-4 web agents to 42.4-49.1 average success rate on WebArena-Lite, above GPT-4-Turbo at 17.6.

## Open Questions

* [Does offloading the KV cache to CPU memory help agentic workloads?](questions/kv-cache-offloading-for-agent-workloads.md) - Agent-serving papers disagree on whether moving idle KV cache off the GPU during tool calls improves throughput.
* [Does speculative decoding still help at large batch sizes?](questions/speculative-decoding-at-large-batch.md) - Papers disagree on whether speculative decoding keeps a speedup above 1 when the server batches many requests.
* [Is Deep Memory Retrieval an adequate benchmark for agent memory?](questions/deep-memory-retrieval-adequacy.md) - MemGPT presents Deep Memory Retrieval as evidence that a memory system is needed, while Zep shows a full-conversation baseline that matches it.
* [Should agent training environments verify tasks with code or with an LLM judge?](questions/code-verification-vs-llm-judge.md) - VeriEnv argues for deterministic code validators and Agent World Model argues that code-only verification is brittle.
* [What is the GSM8K score of Sheared-LLaMA 2.7B?](questions/sheared-llama-gsm8k-discrepancy.md) - Two papers report GSM8K scores for Sheared-LLaMA 2.7B that differ widely (2.7 and 23.96).
* [Which SWE-bench Verified scores are comparable?](questions/swe-bench-verified-comparability.md) - Papers quote the same systems on SWE-bench Verified with different scores and different rollout budgets.
* [Why do reported EAGLE-3 numbers differ so much between papers?](questions/eagle-3-baseline-variance.md) - EAGLE-3 speedup and acceptance length for the same target model differ widely across the papers that re-measure it.
