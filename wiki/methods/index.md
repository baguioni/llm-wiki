# Methods

* [AdaSPEC](adaspec.md) - Selective knowledge distillation for speculative-decoding drafts that trains the draft only on the top-k fraction of tokens where its KL to the target exceeds that of a DistillSpec-distilled reference copy, to raise acceptance rate within the draft's limited capacity.
* [Agentless](agentless.md) - Pipeline-based, non-agent scaffold for SWE-bench issue resolution with localization, repair, and test-based patch selection steps, used as a baseline scaffold and as a base for simplified variants.
* [AutoGen](autogen.md) - Multi-agent conversation framework that papers in this wiki cite as a source of agent workflows and as an example of a dynamic multi-agent workload for LLM serving.
* [Chain-of-Thought Prompting](chain-of-thought.md) - Prompting strategy in which the model writes step-by-step reasoning before its answer or action, used in this wiki's papers as an agent component and as a single-agent baseline.
* [Chunked prefill](chunked-prefill.md) - Technique that splits a prompt's prefill into chunks so that each chunk shares a batch with decoding requests, as the wiki's papers describe and use it.
* [Continuous batching](continuous-batching.md) - Batching scheme for LLM serving in which requests join and leave the running batch between forward passes, as the wiki's papers describe and rely on it.
* [DFlash](dflash.md) - Speculative decoding drafter that uses a lightweight block diffusion model, conditioned on target hidden features through KV injection, to draft a whole token block in one forward pass.
* [DistillSpec](distillspec.md) - White-box knowledge distillation of the draft model toward the target model, with on-policy draft-generated data and a task-tuned divergence, to raise the acceptance rate of speculative decoding.
* [DPO](dpo.md) - Policy optimization from pairs of winning and losing responses to the same input, which avoids explicitly modeling the reward and is used offline by Agent-RLVR.
* [DSpark](dspark.md) - Speculative decoding framework that adds a lightweight sequential head to a parallel DFlash-style drafter and schedules per-request verification length from calibrated confidence and engine load.
* [DVFS (Dynamic Voltage and Frequency Scaling)](dvfs.md) - Changing the operating frequency or voltage point of a CPU, GPU, or NPU to trade inference speed for power, studied in this wiki for mobile LLM inference and for agentic LLM serving on GPUs.
* [EAGLE](eagle.md) - Speculative sampling method whose draft model performs autoregression at the feature level, reusing the target model's top-layer features and LM head; predecessor of EAGLE-2 and EAGLE-3.
* [EAGLE-2](eagle-2.md) - Successor of EAGLE that builds a context-aware dynamic draft tree from the draft model's confidence; the direct baseline of EAGLE-3.
* [EAGLE-3](eagle-3.md) - Speculative sampling draft model that predicts tokens directly from fused low-, mid-, and high-level target features and is trained with training-time test; the most re-measured baseline among the wiki's speculative decoding papers.
* [Early exit](early-exit.md) - Stopping a token's forward pass at an intermediate layer and predicting from that layer's hidden state, used in the wiki's papers as a self-speculative draft (LayerSkip) and to prune low-value branches of a verification tree (Lever).
* [Execution-free verifier](execution-free-verifier.md) - A trained model that scores an agent trajectory or patch for correctness without running code, used to select among candidates at test time and as a reward signal in RL.
* [FR-Spec](fr-spec.md) - Frequency-ranked draft vocabulary truncation that restricts a drafter's LM head to high-frequency tokens to cut LM-head latency, used by EAGLE-3 and adopted by HyCo for its phone NPU drafters.
* [Generalized Knowledge Distillation (GKD)](gkd.md) - Knowledge distillation for autoregressive models that trains the student on a mix of fixed and self-generated (on-policy) sequences with teacher token probabilities as labels and a free choice of divergence; the on-policy variant is one of the recipes DistillSpec uses for draft models.
* [GRPO](grpo.md) - Group Relative Policy Optimization, a policy-gradient RL objective that samples a group of rollouts per prompt and uses each rollout's reward relative to its group as the advantage.
* [HAT](hat.md) - Device-cloud framework that combines U-shaped split inference with speculative decoding, drafting on the device from the LLM's shallow layers, head, and a distilled adapter, with prompt chunking and parallel drafting to hide transfer and drafting delays.
* [HyCo](hyco.md) - Mobile-cloud speculative decoding that drafts a hybrid tree on the phone NPU, taking depth from the verifier's own MTP head (fed with state the server returns) and width from one pass of a small language model.
* [I-DLM (Introspective Diffusion Language Model)](i-dlm.md) - Diffusion LM converted from a pretrained AR model with causal attention, logit shift, and an all-masked loss, decoded by introspective strided decoding, which proposes tokens at masks and verifies the previous proposals with the p/q rule in the same forward pass; a lossless gated-LoRA variant makes it a self-speculative decoder.
* [Knowledge Distillation](knowledge-distillation.md) - Training a smaller student model under the supervision of a larger teacher model, used in this wiki to retrain pruned LLMs and to align speculative-decoding draft models with their targets.
* [KV cache](kv-cache.md) - The per-token key and value tensors that an LLM keeps from earlier tokens so that later tokens do not recompute them, and the object that most serving papers in the wiki manage, share, move, or shrink.
* [KV cache offloading](kv-cache-offloading.md) - Moving KV cache that is not immediately needed from GPU HBM to CPU DRAM or lower storage tiers and reloading it on demand, to extend the effective KV cache capacity of a serving node.
* [KV cache swapping](kv-cache-swapping.md) - Moving a paused request's KV cache from GPU memory to CPU memory and back, so that the context is neither recomputed nor left idle on the GPU.
* [KV injection](kv-injection.md) - Conditioning mechanism from DFlash that injects fused target-model hidden features into the Key and Value projections of every draft layer instead of feeding them only as drafter inputs.
* [LangChain](langchain.md) - LLM orchestration framework for composing LLM calls and tools into applications, which papers in this wiki use as the application layer above serving systems and as a baseline client.
* [LayerSkip](layerskip.md) - Training recipe (depth-increasing layer dropout plus a shared-LM-head early exit loss) that makes a model's early layers usable as a draft, followed by self-speculative decoding in which the first E layers draft and the remaining layers verify with one shared KV cache.
* [Lever](lever.md) - Speculative decoding system for smartphones with a flash-resident target, combining gain-per-latency token tree construction, early-exit pruning of the verification tree, and CPU-NPU split execution.
* [llama.cpp](llama-cpp.md) - An open-source, community-maintained LLM inference framework in C/C++ that the wiki's papers measure on mobile CPU, GPU, and NPU backends and extend for on-device diffusion LLM inference.
* [LLM-as-a-Judge](llm-as-a-judge.md) - Use of an LLM to decide whether an agent trajectory or output is correct, applied in this wiki's papers as a training reward and as an evaluation metric, and contrasted with executable, deterministic verification.
* [LLM-Pruner](llm-pruner.md) - A structured pruning method for LLMs that the wiki's papers use only as a comparison baseline for Sheared-LLaMA and Minitron.
* [LMCache](lmcache.md) - KV cache storage and movement layer for vLLM and SGLang that operates on cache blocks in physical storage tiers, used by papers in this wiki as an offloading baseline and as the layer below semantic cache edits.
* [Lossy acceptance rules](lossy-acceptance.md) - Verification rules for speculative decoding that accept drafted tokens the target would not necessarily sample, trading exact preservation of the target's output distribution for higher acceptance, such as HyCo's epsilon-threshold acceptance, Medusa's typical acceptance, and I-DLM's relaxed acceptance.
* [Medusa](medusa.md) - Speculative decoding approach that attaches extra decoding heads to the target model, which predict several draft tokens in parallel from the same hidden state without a separate draft model.
* [MemGPT](memgpt.md) - OS-inspired LLM system that uses function calls to page information between a fixed context window and external storage, a technique its authors call virtual context management.
* [MetaGPT](metagpt.md) - Multi-agent framework that assigns software-development roles to LLMs, used by LLM serving papers in this wiki as a multi-agent programming workload.
* [Multi-Token Prediction (MTP)](multi-token-prediction.md) - A module that ships with the target model (DeepSeek-V3, DeepSeek-V4, Qwen3.5, Gemma 4 in the wiki's papers) and predicts tokens beyond the next one, reused as the drafter for speculative decoding.
* [OpenHands](openhands.md) - Open-source coding agent scaffold that runs a model in a sandbox over multiple turns, used in the wiki's papers as an SWE-bench agent, a rollout scaffold for training, and a serving workload.
* [Osprey](osprey.md) - Drafter construction that prunes a pretrained small LM to a few layers, pretrains it once on generic web text with no target, and then adapts it to each target with EAGLE-3 training-time test, raising acceptance length over a from-scratch EAGLE-3.
* [PagedAttention](paged-attention.md) - Memory management technique from vLLM that stores the KV cache in non-contiguous blocks tracked by a per-request page table, as the wiki's papers describe and reuse it.
* [PARD](pard.md) - Parallel drafter that fine-tunes a small autoregressive language model with mask tokens to predict K draft tokens in one forward pass, target-independent in PARD and dual-mode with confidence-adaptive loss weighting in PARD-2.
* [PEARL](pearl.md) - Parallel speculative decoding method that drafts the next round during ongoing verification, preparing only for the outcome in which all draft tokens are accepted.
* [Prefix caching](prefix-caching.md) - Reuse of the KV cache of a shared prompt prefix across LLM requests, so that the prefill of the prefix is not recomputed.
* [Proactive edge drafting](proactive-edge-drafting.md) - Continuing to draft on the edge device while the server verifies the previous draft, and reusing that work when the verified path matches, introduced by SpecEdge and re-measured on a phone NPU by HyCo.
* [Program-aware scheduling](program-aware-scheduling.md) - Scheduling LLM serving at the level of the agentic program (all model invocations and tool calls of one agent workflow) instead of the individual request.
* [RadixAttention](radix-attention.md) - SGLang's technique for automatic KV cache reuse, which keeps the cache of all requests as an LRU cache in a radix tree and schedules requests by matched prefix length.
* [ReAct](react.md) - Agent loop in which an LLM alternates a reasoning trace (thought), an action, and the observation returned by the environment, used as the base scaffold or baseline by many agent papers in this wiki.
* [Reflexion](reflexion.md) - Verbal reinforcement framework in which an LLM agent writes self-reflections on task feedback and keeps them in an episodic memory that conditions its next trial, with no weight updates.
* [Retrieval-Augmented Generation](retrieval-augmented-generation.md) - Approach that retrieves relevant external documents and inserts them into the LLM prompt before generation, used in this wiki's papers as a framework module, a non-interactive baseline, and the starting point for agent memory systems.
* [Self-speculative decoding](self-speculative-decoding.md) - Speculative decoding in which the draft comes from the target model itself (its early layers, a subset of its layers, or masked positions of the same forward pass) instead of a separate draft model, as in LayerSkip, Draft & Verify, SWIFT, SDFP, and I-DLM.
* [Sequoia](sequoia.md) - Tree-based speculative decoding method that the wiki's papers describe as using fixed (static) draft tree structures and pruning unpromising branches, used as a comparison point and as a source of tree construction.
* [SGLang](sglang.md) - Language and serving runtime for LLM programs that reuses the KV cache through RadixAttention, and that later papers use as a baseline, a host engine, or a deployment target.
* [Sheared-LLaMA](sheared-llama.md) - LLM-shearing prunes LLaMA2-7B to a pre-specified 1.3B or 2.7B architecture with targeted structured pruning and continues pre-training with dynamic batch loading; the name covers both the method and the resulting models.
* [SpecEdge](specedge.md) - Edge-assisted serving framework that drafts on edge GPUs and verifies on a server GPU, exchanging only tokens, with proactive edge drafting and pipeline-aware server scheduling; also the base engine and SLM-only baseline of HyCo.
* [SpecExec](specexec.md) - Speculative decoding method that deterministically builds a large draft tree of the most probable continuations with a parallel shortest-path search and validates it as a cache in one target-model pass.
* [SpecInfer](specinfer.md) - Speculative inference system with tree-structured drafts and token tree verification, used by the wiki's papers as a baseline and as a reference setup.
* [Speculative Decoding](speculative-decoding.md) - Lossless LLM inference acceleration in which a cheap drafter proposes several tokens and the target model verifies them in one parallel pass; hub page for the 26 papers in this wiki that change the drafter, the verification, the training, the system, or the deployment.
* [Speculative Speculative Decoding (SSD)](speculative-speculative-decoding.md) - Framework that runs drafting in parallel with verification by pre-speculating, on a separate device, for a set of predicted verification outcomes held in a speculation cache.
* [Structured Pruning](structured-pruning.md) - Model compression that removes whole groups of parameters (layers, attention heads, neurons, embedding channels) so that the result is a smaller dense model, usually followed by retraining.
* [SWE-agent](swe-agent.md) - LM agent for software engineering that pairs a language model with an agent-computer interface of custom file viewing, search, and editing commands, and solves 12.47% of SWE-bench with GPT-4 Turbo.
* [Test-time scaling](test-time-scaling.md) - Spending more compute at inference, by sampling several attempts and selecting one with a verifier or counting any success, to raise an agent's task success rate.
* [ThunderAgent](thunderagent.md) - Agentic inference system that schedules whole agent workflows as programs, pausing and restoring them by execution phase and context length to avoid KV cache thrashing, with a global waiting queue across GPU nodes and lifecycle-aware tool resource management.
* [Training-Time Test](training-time-test.md) - Draft-model training technique from EAGLE-3 that simulates multi-step drafting during training by feeding the draft model's own outputs back as inputs, so the draft adapts to self-generated inputs.
* [Tree-based speculation](tree-based-speculation.md) - Family of speculative decoding methods in which the drafter proposes a tree of candidate tokens, giving the verifier several options per position, and the target verifies the whole tree in one pass.
* [vLLM](vllm.md) - LLM inference engine that the wiki's papers use as a baseline, as the system they extend, or as the serving host for their experiments.
