# Papers

* [Agent World Model: Infinity Synthetic Environments for Agentic Reinforcement Learning](wangAgentWorldModel2026.md) - Open-source pipeline that synthesizes 1,000 code-driven, SQLite-backed, MCP-exposed tool-use environments with verification code, used to train Qwen3 agents with GRPO that generalize to out-of-distribution benchmarks.
* [Agent-RLVR: Training Software Engineering Agents via Guidance and Environment Rewards](daAgentRLVRTrainingSoftware2025.md) - RLVR training framework for software engineering agents that has the agent reattempt failed tasks with teacher-generated guidance and then updates the policy with offline DPO on unit-test rewards.
* [AgentDropout: Dynamic Agent Elimination for Token-Efficient and High-Performance LLM-Based Multi-Agent Collaboration](wangAgentDropoutDynamicAgent2025.md) - Topology optimization for LLM multi-agent systems that learns communication-graph adjacency matrices, then drops low-contribution agents per round (Node Dropout) and low-weight edges (Edge Dropout) to cut tokens and raise accuracy.
* [AgentScope: A Flexible yet Robust Multi-Agent Platform](gaoAgentScopeFlexibleRobust2024.md) - Developer-centric multi-agent platform built on message exchange, with fault tolerance, multi-modal, tool, and RAG support, and an actor-based distributed mode.
* [Autellix: An Efficient Serving Engine for LLM Agents as General Programs](luoAutellixEfficientServing.md) - LLM serving system that schedules LLM calls by the attained service of their parent agentic program (PLAS, ATLAS) and routes calls across engines by program data locality.
* [Collaborative Speculative Inference for Efficient LLM Inference Serving](gaoCollaborativeSpeculativeInference.md) - CoSine decouples speculative drafting from verification across heterogeneous nodes, with drafter routing, confidence-based token fusion, and pipeline scheduling.
* [Compact Language Models via Pruning and Knowledge Distillation](muralidharanCompactLanguageModels2024.md) - Empirical study of structured pruning (depth, width, attention, MLP) plus distillation-based retraining that yields a list of compression best practices and the Minitron 8B and 4B models derived from Nemotron-4 15B.
* [Decoding Speculative Decoding](yanDecodingSpeculativeDecoding2025.md) - Empirical study showing that speculative decoding throughput is bottlenecked by draft model latency and depth, and that wide, shallow pruned draft models give up to 111% higher throughput.
* [DFlash: Block Diffusion for Flash Speculative Decoding](chenDFlashBlockDiffusion2026.md) - Speculative decoding framework whose drafter is a lightweight block diffusion model, conditioned on target hidden features through KV injection, that drafts a whole token block in one forward pass.
* [DistillSpec: Improving Speculative Decoding via Knowledge Distillation](zhouDistillSpecImprovingSpeculative2024.md) - Uses white-box knowledge distillation with on-policy draft-generated data and a task-tuned divergence to align the draft model with the target model and raise speculative decoding speed.
* [DSpark: Confidence-Scheduled Speculative Decoding with Semi-Autoregressive Generation](chengDSparkConfidenceScheduledSpeculative2026.md) - Speculative decoding framework that adds a lightweight sequential head to a parallel drafter and schedules per-request verification length from calibrated confidence and engine load, deployed in the DeepSeek-V4 serving system.
* [DualPath: Breaking the Storage Bandwidth Bottleneck in Agentic LLM Inference](wuDualPathBreakingStorage2026.md) - Inference system for agentic workloads that loads KV-Cache through decode engines as well as prefill engines, pooling the storage NIC bandwidth of all engines in a prefill-decode disaggregated cluster.
* [EAGLE-3: Scaling up Inference Acceleration of Large Language Models via Training-Time Test](liEAGLE3ScalingInference2025.md) - Speculative sampling draft model that drops EAGLE's feature prediction for direct token prediction with training-time test and fuses low-, mid-, and high-level target features.
* [Efficient On-Device Diffusion LLM Inference with Mobile NPU](wangEfficientOnDeviceDiffusion2026.md) - llada.cpp, an NPU-aware inference framework that speeds up block-wise diffusion LLM generation on smartphones with multi-block speculative decoding, dual-path progressive revision, and a swap-optimized memory runtime.
* [Idleness Is Relative: Exploiting Tool-Call Idle Windows for Offloading in Agentic Systems with MORI](xiaIdlenessRelativeExploiting2026.md) - MORI is an agent serving scheduler that ranks programs by a continuous idleness metric and places their KV caches across GPU HBM and CPU DRAM with admission control at both tiers.
* [InferCept: Efficient Intercept Support for Augmented Large Language Model Inference](abhyankarInferCeptEfficientIntercept2024.md) - LLM inference framework that handles tool, model, and human interceptions by choosing preserve, discard, or swap per request to minimize GPU memory waste.
* [Is Your NPU Ready for LLMs? Dissecting the Hidden Efficiency Bottlenecks in Mobile LLM Inference](caiYourNPUReady2026.md) - Cross-layer measurement study of mobile LLM inference across five frameworks and CPU, GPU, and NPU backends, with a backend-level energy profiler (PowerBench) and an energy-oriented NPU configuration.
* [KAIROS: Stateful, Context-Aware Power-Efficient Agentic Inference Serving](yuanKAIROSStatefulContextAware2026.md) - Power management system for agentic LLM serving that uses aggregate agent context as the control signal for GPU frequency, per-instance concurrency, and multi-instance routing, cutting average GPU power by 27% while meeting a per-agent throughput SLO.
* [Learning To Draft: Adaptive Speculative Decoding with Reinforcement Learning](zhangLearningDraftAdaptive2026.md) - Trains two co-adaptive reinforcement learning policies, one for draft tree depth and one for verification size, with per-cycle throughput as the reward, on top of Eagle3.
* [Leyline: KV Cache Directives for Agentic Inference](maLeylineKVCache2026.md) - Serving-side primitive that lets an agent policy issue (span, replacement) directives to splice the KV cache in place, using a closed-form RoPE delta-rotation on MLA models so the unchanged prefix and downstream slots are not re-prefilled.
* [LK Losses: Direct Acceptance Rate Optimization for Speculative Decoding](samarinLKLossesDirect2026.md) - Training objectives for speculative decoding draft models that optimize the acceptance rate directly, as a negative log-acceptance loss or an adaptively blended KL and total variation loss.
* [MemGPT: Towards LLMs as Operating Systems](packerMemGPTLLMsOperating2024.md) - OS-inspired LLM system that uses function calls to page information between the context window and external storage, giving a fixed-context LLM the illusion of extended context.
* [Parrot: Efficient Serving of LLM-based Applications with Semantic Variable](linParrotEfficientServing2024.md) - LLM service system that exposes application-level knowledge through the Semantic Variable abstraction so the service can analyze request dependencies and shared prompts and optimize end-to-end application performance.
* [R2E-Gym: Procedural Environments and Hybrid Verifiers for Scaling Open-Weights SWE Agents](jainR2EGymProceduralEnvironments2025.md) - Procedurally curated gym of more than 8.1K executable SWE tasks built from commits (SweGen), plus a hybrid execution-based and execution-free verifier that reaches 51% on SWE-Bench Verified with a 32B open-weight model.
* [Reflexion: Language Agents with Verbal Reinforcement Learning](shinnReflexionLanguageAgents2023.md) - Framework that reinforces LLM agents without weight updates by having them write verbal self-reflections on task feedback and keep them in an episodic memory buffer for later trials.
* [Safe and Scalable Web Agent Learning via Recreated Websites](chaeSafeScalableWeb2026.md) - VeriEnv uses a coding agent to clone real websites into executable synthetic environments with a Python SDK, so web agents can train on self-generated tasks with deterministic, programmatically verified rewards.
* [SAGA: Workflow-Atomic Scheduling for AI Agent Inference on GPU Clusters](guoSAGAWorkflowAtomicScheduling2026.md) - Distributed scheduler that treats a whole agent workflow as the schedulable unit, with workflow-aware KV cache eviction, session-affinity batching, and task-level fairness.
* [SDFP: Speculative Decoding with FIT-Pruned Models for Training-Free and Plug-and-Play LLM Acceleration](weiSDFPSpeculativeDecoding2026.md) - Training-free speculative decoding that builds the draft model by pruning the target LLM's least sensitive layers, ranked by Fisher Information Trace computed on WikiText2.
* [SGLang: Efficient Execution of Structured Language Model Programs](zhengSGLangEfficientExecution2024.md) - A Python-embedded language and co-designed runtime for multi-call LLM programs that reuses the KV cache through a radix tree (RadixAttention) and speeds up constrained decoding with a compressed finite state machine.
* [Sheared LLaMA: Accelerating Language Model Pre-Training via Structured Pruning](xiaShearedLLaMAAccelerating2024.md) - LLM-shearing prunes LLaMA2-7B to a pre-specified 1.3B or 2.7B architecture and continues pre-training with dynamic batch loading, using 50B tokens.
* [SpecEdge: Scalable Edge-Assisted Serving Framework for Interactive LLMs](parkSpecEdgeScalableEdgeAssisted2025.md) - Edge-assisted LLM serving framework that splits speculative decoding into drafting on consumer-grade edge GPUs and verification on server GPUs, with proactive edge drafting and pipeline-aware server scheduling.
* [SpecExec: Massively Parallel Speculative Decoding for Interactive LLM Inference on Consumer Devices](svirschevskiSpecExecMassivelyParallel2024.md) - Speculative decoding method that builds a large deterministic draft tree with a parallel shortest-path search and validates it as a cache in one offloaded target-model pass, for running 50B+ models on consumer GPUs.
* [SpecForge: A Flexible and Efficient Open-Source Training Framework for Speculative Decoding](liSpecForgeFlexibleEfficient2026.md) - Open-source framework for training EAGLE-3 draft models that decouples the target model (run on SGLang) from the draft model (trained with ZeRO Stage 2), released with the SpecBundle suite of draft models.
* [Speculative Speculative Decoding](kumarSpeculativeSpeculativeDecoding2026.md) - Framework (SSD) and optimized algorithm (Saguaro) that run drafting in parallel with verification by pre-speculating for predicted verification outcomes on a separate device.
* [SuffixDecoding: Extreme Speculative Decoding for Emerging AI Applications](oliaroSuffixDecodingExtremeSpeculative2024.md) - Model-free speculative decoding that drafts tokens from suffix trees over the current request and prior outputs, with speculation length adapted to the pattern match length, aimed at repetitive agentic workloads.
* [SWE-agent: Agent-Computer Interfaces Enable Automated Software Engineering](yangSWEagentAgentComputerInterfaces2024.md) - Introduces the agent-computer interface (ACI) and SWE-agent, an LM agent whose custom file viewer, editor, search, and context management commands resolve 12.47% of SWE-bench with GPT-4 Turbo.
* [SWE-RL: Advancing LLM Reasoning via Reinforcement Learning on Open Software Evolution](weiSWERLAdvancingLLM2025.md) - Reinforcement learning on GitHub pull-request data with a patch-similarity reward that trains Llama3-SWE-RL-70B to a 41.0% solve rate on SWE-bench Verified.
* [SWE-RM: Execution-Free Feedback for Software Engineering Agents](shumSWERMExecutionfreeFeedback2025.md) - Execution-free reward model for software engineering agents, trained for ranking, discrimination (AUC), and calibration (ECE) so that it works for both test-time scaling and reinforcement learning.
* [SYMPHONY: Improving Memory Management for LLM Inference Workloads](agarwalSYMPHONYImprovingMemory2024.md) - Cluster-level LLM serving system that uses advisory requests from multi-turn workloads to prefetch and migrate K,V caches off the critical path, enabling request-level load balancing.
* [The Synergy of Speculative Decoding and Batching in Serving Large Language Models](suSynergySpeculativeDecoding2023.md) - Characterization of batched speculative decoding showing that the optimal speculation length shrinks as batch size grows, with an adaptive scheme that picks the speculation length per batch size from a profiled look-up table.
* [ThunderAgent: A Simple, Fast and Program-Aware Agentic Inference System](kangThunderAgentSimpleFast2026.md) - Agentic inference system that schedules whole agent workflows as programs, pausing and migrating them to avoid KV cache thrashing and cross-node memory imbalance, and manages tool environments by program lifecycle.
* [VOYAGER: An Open-Ended Embodied Agent with Large Language Models](wangVOYAGEROpenEndedEmbodied.md) - LLM-powered embodied lifelong learning agent for Minecraft that combines an automatic curriculum, a skill library of executable code, and iterative prompting with self-verification, using blackbox GPT-4 queries.
* [Wan: Open and Advanced Large-Scale Video Generative Models](wanWanOpenAdvanced2025.md) - Open suite of diffusion-transformer video foundation models (1.3B and 14B) with a 3D causal VAE, a data and training pipeline, the Wan-Bench evaluation, and downstream image-to-video, editing, personalization, real-time, and audio models.
* [WebArena: A Realistic Web Environment for Building Autonomous Agents](zhouWebArenaRealisticWeb2024.md) - A standalone, self-hostable web environment of fully functional websites with an 812-task benchmark that scores web agents by the functional correctness of task completion.
* [Weblica: Scalable and Reproducible Training Environments for Visual Web Agents](karWeblicaScalableReproducible2026.md) - Framework that builds offline web training environments by HTTP-level caching of real sites and LLM-based synthesis of new sites, used to train screenshot-only web agents with SFT followed by RL.
* [WebRL: Training LLM Web Agents via Self-Evolving Online Curriculum Reinforcement Learning](qiWebRLTrainingLLM2025.md) - Online curriculum reinforcement learning framework that trains open LLMs into web agents using self-generated tasks, a learned outcome reward model, and a KL-constrained off-policy update.
* [WebSailor-V2: Bridging the Chasm to Proprietary Agents via Synthetic Data and Scalable Reinforcement Learning](liWebSailorV2BridgingChasm2025.md) - Post-training pipeline for an open-source web agent that combines the SailorFog-QA-V2 synthetic dataset, an SFT cold start, and GRPO-based RL in simulated and real environments on Qwen3-30B-A3B.
* [When Parallel Drafter Meets Parallel Speculative Decoding](liuWhenParallelDrafter2026.md) - DPara is a parallel speculative decoding framework that precomputes a diffusion drafter backbone for every acceptance boundary during verification, so only a lightweight autoregressive head stays on the critical path and no serial fallback occurs.
* [When RL Meets Adaptive Speculative Training: A Unified Training-Serving System](wangWhenRLMeets2026.md) - Aurora, a unified training-serving system that trains a speculative-decoding draft model online from live inference traces as an asynchronous RL problem and hot-swaps updates into an SGLang server.
* [Zep: A Temporal Knowledge Graph Architecture for Agent Memory](rasmussenZepTemporalKnowledge2025.md) - Agent memory layer built on Graphiti, a temporally-aware knowledge graph engine with episodic, semantic entity, and community subgraphs and hybrid graph retrieval.
