# VOYAGER: An Open-Ended Embodied Agent with Large Language Models

Text source: arXiv HTML, version `2305.16291v2`.

## Summary

[Voyager](../methods/voyager.md) is presented as the first LLM-powered embodied lifelong learning agent in Minecraft that continuously explores the world, acquires diverse skills, and makes novel discoveries without human intervention.[^wangVOYAGEROpenEndedEmbodied] It has three components: an [automatic curriculum](../methods/automatic-curriculum.md) that maximizes exploration, an ever-growing [skill library](../methods/skill-library.md) of executable code, and an [iterative prompting mechanism](../methods/iterative-prompting.md) that incorporates environment feedback, execution errors, and self-verification.[^wangVOYAGEROpenEndedEmbodied] Voyager interacts with GPT-4 through blackbox queries and needs no model parameter fine-tuning.[^wangVOYAGEROpenEndedEmbodied]

The paper reports that Voyager obtains 3.3× more unique items, travels 2.3× longer distances, and unlocks key tech tree milestones up to 15.3× faster than prior SOTA, and that it can use the learned skill library in a new Minecraft world to solve novel tasks from scratch.[^wangVOYAGEROpenEndedEmbodied]

## Contributions

- An automatic curriculum, generated by GPT-4 from the overarching goal of "discovering as many diverse things as possible", described as an in-context form of novelty search.[^wangVOYAGEROpenEndedEmbodied]
- A skill library that stores action programs that solved a task, indexed by the embedding of their description, so complex skills can be composed from simpler programs.[^wangVOYAGEROpenEndedEmbodied]
- An iterative prompting mechanism that uses code as the action space and refines programs with environment feedback, execution errors, and a self-verification module.[^wangVOYAGEROpenEndedEmbodied]
- A systematic evaluation against [ReAct](../methods/react.md), [Reflexion](../methods/reflexion.md), and [AutoGPT](../methods/autogpt.md) re-interpreted for [MineDojo](../benchmarks/minedojo.md).[^wangVOYAGEROpenEndedEmbodied]

## Method

### Automatic curriculum

The curriculum prompt to GPT-4 contains: directives encouraging diverse behaviors and imposing constraints; the agent's current state (inventory, equipment, nearby blocks and entities, biome, time, health and hunger bars, position); previously completed and failed tasks; and additional context from GPT-3.5 self-asking and self-answering questions.[^wangVOYAGEROpenEndedEmbodied] GPT-3.5 is used instead of GPT-4 for standard NLP tasks due to budgetary considerations.[^wangVOYAGEROpenEndedEmbodied] GPT-4 is asked to reason about current progress first and then suggest the next task ([chain-of-thought](../methods/chain-of-thought.md) prompting).[^wangVOYAGEROpenEndedEmbodied]

A warm-up schedule adds information to the prompt according to how many tasks have been completed (Table A.1):[^wangVOYAGEROpenEndedEmbodied]

| Information in the prompt | After how many tasks are completed |
|---|---|
| core inventory (only including log, planks, stick, crafting table, furnace, dirt, coal, pickaxe, sword, and axe) | 0 |
| equipment | 0 |
| nearby blocks | 0 |
| position | 0 |
| nearby entities | 5 |
| full inventory | 7 |
| other blocks that are recently seen | 10 |
| biome | 10 |
| health bar | 15 |
| hunger bar | 15 |
| time | 15 |
| additional context | 15 |

### Skill library

- Each skill is executable code. The library is a vector database: the key is the embedding vector of the program description (generated by GPT-3.5) and the value is the program.[^wangVOYAGEROpenEndedEmbodied]
- For retrieval, GPT-3.5 generates a general suggestion for solving the task, which is combined with environment feedback as the query context; the top-5 relevant skills are retrieved.[^wangVOYAGEROpenEndedEmbodied]
- The code-generation prompt contains guidelines for code generation, control primitive APIs and retrieved skills, the generated code from the last round with environment feedback, execution errors and critique, the agent's current state, and chain-of-thought prompting.[^wangVOYAGEROpenEndedEmbodied]
- Control primitives implemented by the authors include `exploreUntil`, `mineBlock`, `craftItem`, `placeItem`, `smeltItem`, `killMob`, `getItemFromChest`, and `depositItemIntoChest`; others come from Mineflayer.[^wangVOYAGEROpenEndedEmbodied]

### Iterative prompting mechanism

- **Environment feedback** shows the intermediate progress of program execution, generated with `bot.chat()` inside control primitive APIs.[^wangVOYAGEROpenEndedEmbodied]
- **Execution errors** from the program interpreter reveal invalid operations or syntax errors.[^wangVOYAGEROpenEndedEmbodied]
- **[Self-verification](../methods/self-verification.md)**: another GPT-4 agent acts as a critic, given Voyager's current state and the task, and reports whether the program achieves the task; if the task fails it provides a critique.[^wangVOYAGEROpenEndedEmbodied]
- The loop repeats until self-verification validates completion, at which point the skill is added to the library and the curriculum is queried for a new objective. If the agent gets stuck after 4 rounds of code generation, the curriculum is queried for another task.[^wangVOYAGEROpenEndedEmbodied]
- To save token usage, a system prompt and a user prompt are concatenated for each response instead of multi-round conversation.[^wangVOYAGEROpenEndedEmbodied]

## Experiments & Results

### Setup

- Models: gpt-4-0314 and gpt-3.5-turbo-0301 for text completion, text-embedding-ada-002 for text embedding.[^wangVOYAGEROpenEndedEmbodied]
- All temperatures are 0 except the automatic curriculum, which uses temperature = 0.1.[^wangVOYAGEROpenEndedEmbodied]
- The simulation environment is built on MineDojo and uses Mineflayer JavaScript APIs for motor controls.[^wangVOYAGEROpenEndedEmbodied]
- Baselines: ReAct, Reflexion, and AutoGPT, re-interpreted to be executable in MineDojo. The task is "explore the world and get as many items as possible" for all baselines.[^wangVOYAGEROpenEndedEmbodied]
- The paper does not compare with methods that take Minecraft screen pixels as input and output low-level controls.[^wangVOYAGEROpenEndedEmbodied]
- Three trials are run for each method.[^wangVOYAGEROpenEndedEmbodied]

### Exploration and map traversal

- Voyager discovers 63 unique items within 160 prompting iterations, 3.3× many novel items compared to its counterparts.[^wangVOYAGEROpenEndedEmbodied]
- Voyager navigates distances 2.3× longer compared to baselines.[^wangVOYAGEROpenEndedEmbodied]

### Ablations

- Replacing the automatic curriculum with a random one drops the discovered item count by 93%.[^wangVOYAGEROpenEndedEmbodied]
- Removing self-verification drops the discovered item count by 73% (reported as −73%).[^wangVOYAGEROpenEndedEmbodied]
- GPT-4 obtains 5.7× more unique items than GPT-3.5 for code generation.[^wangVOYAGEROpenEndedEmbodied]
- Voyager without the skill library tends to plateau in the later stages.[^wangVOYAGEROpenEndedEmbodied]

### Other findings

- With gpt-4-0613 instead of gpt-4-0314 the performance is roughly the same.[^wangVOYAGEROpenEndedEmbodied]
- Given human feedback (human as a critic, or human as a curriculum), Voyager constructs 3D structures such as a Nether Portal and a house.[^wangVOYAGEROpenEndedEmbodied]

## Limitations

- **Cost.** The GPT-4 API is 15× more expensive than GPT-3.5, and Voyager requires the code generation quality of GPT-4.[^wangVOYAGEROpenEndedEmbodied]
- **Inaccuracies.** The agent sometimes gets stuck and fails to generate the correct skill. The self-verification module may also fail, for example by not recognizing spider string as a success signal of beating a spider.[^wangVOYAGEROpenEndedEmbodied]
- **Hallucinations.** The automatic curriculum occasionally proposes unachievable tasks such as crafting a "copper sword". GPT-4 tends to use cobblestone as a fuel input and may call functions absent from the provided control primitive APIs.[^wangVOYAGEROpenEndedEmbodied]
- Voyager does not support visual perception, because the available GPT-4 API was text-only at the time of writing.[^wangVOYAGEROpenEndedEmbodied]
- Voyager relies on the high-level Mineflayer API and does not address 3D perception or sensorimotor control.[^wangVOYAGEROpenEndedEmbodied]
- The diamond level was unlocked in 1 of 3 trials.[^wangVOYAGEROpenEndedEmbodied]
