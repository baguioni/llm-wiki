# DistillSpec: Improving Speculative Decoding via Knowledge Distillation

Text source: arXiv HTML, version `2310.08461v2`.

## Summary

[Speculative decoding](../methods/speculative-decoding.md) (SD) uses a small draft model to generate several tokens, which a larger target model verifies in parallel, so that the output follows the target model distribution.[^zhouDistillSpecImprovingSpeculative2024] The realized speedup depends on the acceptance rate of drafted tokens, which is tied to how well the draft and target token distributions are aligned.[^zhouDistillSpecImprovingSpeculative2024]

DistillSpec uses white-box [knowledge distillation](../methods/knowledge-distillation.md) (KD) to align the draft model with the target model before applying SD. Unlike standard KD, which aims to improve the student's task performance, its goal is a higher acceptance rate.[^zhouDistillSpecImprovingSpeculative2024] Two design choices matter: on-policy data generated by the draft model, and a divergence function tailored to the task and decoding strategy.[^zhouDistillSpecImprovingSpeculative2024] The abstract reports $10-45\%$ speedups over standard SD, an average speedup of $26\%$ when the distilled draft is transferred to unseen tasks, and a $6-10\times$ latency reduction when distillation of the target is combined with DistillSpec in a model-garden setting.[^zhouDistillSpecImprovingSpeculative2024]

## Contributions

- DistillSpec, a method that uses KD to improve draft-target alignment, reported to improve SD speed by 10$-$45% while preserving model performance across datasets under greedy and non-greedy sampling.[^zhouDistillSpecImprovingSpeculative2024]
- An analysis of the distillation recipe (training data generation and divergence function), including the differences between standard KD and distillation tailored for SD.[^zhouDistillSpecImprovingSpeculative2024]
- An extension to lossy SD for control over the quality-latency trade-off, and guidance on combining KD and SD when several models are available.[^zhouDistillSpecImprovingSpeculative2024]
- Theorem 4.1, which bounds the acceptance rate from below in terms of the on-policy KD loss.[^zhouDistillSpecImprovingSpeculative2024]

## Method

### Background and efficiency measures

- Each SD step samples a block of $\gamma$ tokens from the draft distribution $q$, then the target model verifies them in parallel and accepts token $y_{t+i}$ with probability $\min(1, p(y_{t+i})/q(y_{t+i}))$. A rejected token is resampled from $p'(y_{t+i}) \propto \max(0, p(y_{t+i}) - q(y_{t+i}))$. If all are accepted, an extra token is sampled from $p(y_{t+\gamma})$.[^zhouDistillSpecImprovingSpeculative2024]
- **Token-level acceptance rate:** $\beta(x,y_{<t}) := \mathbb{E}_{y_t\sim q(y_t)}[\min(1, p(y_t)/q(y_t))]$, which satisfies $\beta(x,y_{<t}) = 1 - D_{\operatorname{TVD}}(p(y_t), q(y_t))$.[^zhouDistillSpecImprovingSpeculative2024]
- **Sequence-level acceptance rate** $\alpha(x)$ (for $\gamma=\infty$): expected number of accepted tokens divided by the expected number of tokens in the output.[^zhouDistillSpecImprovingSpeculative2024]
- **Block efficiency** $\tau(x)$: expected number of accepted tokens per block, with maximum $\gamma+1$. If the token-level rates are i.i.d., $\tau(x) = (1-\alpha^{\gamma+1})/(1-\alpha)$.[^zhouDistillSpecImprovingSpeculative2024]
- **Expected speedup:** $\tau(x)/(c\gamma+1)$, where the relative latency $c$ is the ratio of the time for one forward pass of the draft model to that of the target model.[^zhouDistillSpecImprovingSpeculative2024]

### Distillation objective

The draft model $\mathscr{M}_q^\theta$ is trained to minimize a divergence $D$ between the target and draft next-token distributions, averaged over tokens, on a training set $\mathscr{G}$ (Eq. 2). White-box access to both models is assumed.[^zhouDistillSpecImprovingSpeculative2024]

KD algorithms compared (Table 1):[^zhouDistillSpecImprovingSpeculative2024]

| Name | Divergence | Training Data ($\mathscr{G}$) |
|---|---|---|
| SeqKD (black-box KD) | FKL | Data generated by teacher $\mathscr{M}_p$ |
| Supervised KD | FKL | Fixed dataset of input-output pairs |
| ImitKD | FKL | Fixed dataset + data generated by $\mathscr{M}_q^\theta$ |
| f-Distill | TVD | Data generated by $\mathscr{M}_q^\theta$ and $\mathscr{M}_p$ |
| On-policy GKD | FKL / JSD | On-policy data from student $\mathscr{M}_q^\theta$ |

- **Choice of divergence.** Maximizing $\alpha(x)$ is equivalent to minimizing the expected TVD between $p$ and $q$ over the target's output distribution (Eq. 3). Even so, directly optimizing TVD does not give the best performance in most settings explored. The paper treats the divergence (forward KL, reverse KL, JSD, TVD) as a hyperparameter to tune per task and decoding strategy.[^zhouDistillSpecImprovingSpeculative2024]
- **Choice of training data.** The model is prompted with a task input from a ground-truth training set and its response is used for distillation. Decoding from a large teacher is expensive, so the paper recommends on-policy data sampled from the draft model, which gives similar or superior performance to target-generated data at a much lower cost.[^zhouDistillSpecImprovingSpeculative2024]
- **Theorem 4.1.** If the draft model achieves on-policy KD loss $\epsilon$ (expected TVD over draft-generated sequences), then $\mathbb{E}_{x\sim X}[\alpha(x)] \geq 1 - T\cdot\mathbb{E}_{x\sim X}[\tfrac{T}{L_p(x)}]\epsilon$, where $T$ is the maximum sequence length and $L_p(x)$ is the expected target output length. When the target output length is always $T$, the bound is $1 - T\epsilon$.[^zhouDistillSpecImprovingSpeculative2024]

### Lossy SD

[Lossy speculative decoding](../methods/lossy-speculative-decoding.md) replaces the acceptance probability with $\min(1, f(p(y_t),\epsilon)/q(y_t))$ for a lenience function $f$ and a free parameter $\epsilon\in[0,1]$ ($\epsilon$ = 1 is lossless). Three lenience functions are evaluated: $f_{\rm lin}(p,\epsilon)=p/\epsilon$, $f_{\rm sq}(p,\epsilon)=p/\epsilon^2$, and $f_{\rm exp}(p,\epsilon)=p^\epsilon$.[^zhouDistillSpecImprovingSpeculative2024]

### Training details

| Hyperparameter | Value |
|---|---|
| training steps | 300,000 |
| batch size | 32 |
| dropout | 0.0 |
| learning rate (LR) | 0.0003 |
| LR warmup steps | 5,000 |
| LR cooldown (begin, end) | (150,000, 300,000) |
| warmup schedule | linear (from 0 to LR) |
| cooldown schedule | cosine decay (from LR to 0.1LR) |

All rows: [^zhouDistillSpecImprovingSpeculative2024]

- Optimizer: Adafactor. The KD-loss temperatures of the target and draft models are both held at 1.0.[^zhouDistillSpecImprovingSpeculative2024]
- All teacher- or student-generated data uses temperature sampling with a temperature of 1.0. SeqKD and f-Distill use online teacher data generation. GKD excludes the static ground-truth data and uses only data from the online student.[^zhouDistillSpecImprovingSpeculative2024]
- Student and teacher in the encoder-decoder experiments are both initialized from models that were supervised fine-tuned on the original training dataset.[^zhouDistillSpecImprovingSpeculative2024]

## Experiments & Results

### Setup

- Models: (1) GPT-like decoder-only Transformers trained on LM1B, target 234M and draft 33M parameters; (2) encoder-decoder T5 v1.1 models, with T5-XL (3B) as target and T5-Small (77M) as draft.[^zhouDistillSpecImprovingSpeculative2024]
- Tasks and metrics: [XSum](../datasets/xsum.md) (ROUGE-2), [CNN/DM](../datasets/cnn-dailymail.md) (ROUGE-2), [WMT EnDe](../datasets/wmt14-en-de.md) (BLEU), [GSM8K](../datasets/gsm8k.md) (accuracy), [LM1B](../datasets/lm1b.md).[^zhouDistillSpecImprovingSpeculative2024]
- Decoding: greedy sampling ($T=0$) and standard temperature sampling ($T=1$), batch size 1.[^zhouDistillSpecImprovingSpeculative2024]
- Latency: target and draft run on the same TPUv4 device without model parallelism. 500 examples are sampled from the test or validation set, wall-clock decoding time is measured at batch size 1, and the mean of three repetitions is reported.[^zhouDistillSpecImprovingSpeculative2024]

### Findings on speedup and transfer

- Section 5.1 states that distillation consistently yields a 10$-$46% improvement in SD speed across datasets, most pronounced with greedy decoding. The abstract, the contribution list, and the Figure 1 caption state 10$-$45%.[^zhouDistillSpecImprovingSpeculative2024]
- Distillation algorithms that use model-generated data give $\sim$20% additional speedup over standard SD on LM1B, XSum, CNN/DM, and GSM8K.[^zhouDistillSpecImprovingSpeculative2024]
- **Transfer.** A draft distilled on GSM8K, tested with zero-shot chain-of-thought prompting on 23 BigBenchHard tasks, raises the average speedup from 1.93$\times$ and 1.78$\times$ to 2.21$\times$ and 2.02$\times$ for greedy and non-greedy decoding. The Figure 1 caption gives this as an average speedup of $26\%$.[^zhouDistillSpecImprovingSpeculative2024]
- **Larger target.** The T5-Small draft distilled from T5-XL, used with a T5-XXL target, outperforms standard SD by $7\%-37\%$ across datasets.[^zhouDistillSpecImprovingSpeculative2024]
- **KD method comparison ($T=1$, $\gamma=7$).** Supervised KD (ground-truth data) ranks lowest in all settings. f-Distill and GKD, which use only model-generated data, outperform the other variants. SeqKD performs poorly although it trains on target-generated data, which the paper takes as evidence that supervision from the target's logits is vital. f-Distill and GKD perform comparably, and GKD gives the best wall-time improvement. Values are given only in Figure 2.[^zhouDistillSpecImprovingSpeculative2024]
- Block efficiency improves across most examples, and empirical block efficiency agrees with the TVD-based theoretical value in the ranking of distilled models.[^zhouDistillSpecImprovingSpeculative2024]
- Supervised KD shows declining acceptance rates after $\sim$40k training steps on XSum and CNNDM.[^zhouDistillSpecImprovingSpeculative2024]
- A high sampling temperature for generating distillation data is needed for the best acceptance rate on XSum, for both draft-generated and target-generated data.[^zhouDistillSpecImprovingSpeculative2024]

### Distillation recipe (Section 5.2)

Four data sources (fixed ground-truth dataset; draft only; target only; draft and target in equal proportion) are crossed with four divergences (FKL, JSD, RKL, TVD) on XSum and GSM8K.[^zhouDistillSpecImprovingSpeculative2024]

| Setting | Best setup for block efficiency |
|---|---|
| XSum, greedy decoding | data from both $\mathscr{M}_q^\theta$ and $\mathscr{M}_p$, with JSD slightly outperforming the other divergences |
| GSM8K, greedy decoding | FKL with only draft-generated data |
| GSM8K, temperature sampling ($T=1$) | RKL with data generated by $\mathscr{M}_p$ |

All rows: [^zhouDistillSpecImprovingSpeculative2024]

- Model-generated data gives better block efficiency than a fixed dataset. Draft-only data is competitive.[^zhouDistillSpecImprovingSpeculative2024]
- Improvements in SD and in downstream task performance are only weakly correlated: a distilled model with high task performance is not necessarily a better-aligned drafter.[^zhouDistillSpecImprovingSpeculative2024]

### Quality vs. latency (Section 5.3)

- **Lossy SD on GSM8K.** Even with a permissive lenience of $\varepsilon=10^{-5}$, $f_{\rm lin}$ still gives high performance but high latency. $f_{\rm sq}$ traces a similar but slightly extended trade-off curve. $f_{\rm exp}$ makes interpolation possible but gives a worse quality-latency trade-off.[^zhouDistillSpecImprovingSpeculative2024]
- **Model garden.** Five T5 sizes are used: T5-Small (77M), T5-Base (250M), T5-Large (800M), T5-XL (3B), T5-XXL (11B). Four pipelines are compared: raw (supervised fine-tuned), distilled, speculative, and DistillSpec (KD on the models, then SD with distilled target and draft).[^zhouDistillSpecImprovingSpeculative2024]

| Dataset | Relative latency | Speedup improvement | Quality |
|---|---|---|---|
| XSum | from 17.3 to 2.7 | 6.4$\times$ | Rouge2 from 23.1 to 23.0 |
| GSM8K | from 15.0 to 1.4 | 10.7$\times$ | accuracy from 33.1 to 34.8 |

All rows: [^zhouDistillSpecImprovingSpeculative2024]

- SD is less effective for smaller model sizes, where the computation times of draft and target are closely matched. Distillation alone gives a better trade-off for smaller models.[^zhouDistillSpecImprovingSpeculative2024]

## Limitations

- No single recipe is best: the divergence function and data construction must be tuned per task and decoding strategy.[^zhouDistillSpecImprovingSpeculative2024]
- Directly optimizing TVD, the theoretically motivated objective, does not give the best performance in most settings explored.[^zhouDistillSpecImprovingSpeculative2024]
- The method assumes white-box access to both models.[^zhouDistillSpecImprovingSpeculative2024]
- Gains on WMT are small: +0.05× to +0.12× in Table C.1.[^zhouDistillSpecImprovingSpeculative2024]
- Theoretical block efficiency sometimes overestimates or underestimates the empirical value, which the paper attributes to possible deviations from the i.i.d. token-level assumption.[^zhouDistillSpecImprovingSpeculative2024]
- The interpolation range of lossy SD can be limited, as in the GSM8K experiment.[^zhouDistillSpecImprovingSpeculative2024]
- Latency is measured at batch size 1.[^zhouDistillSpecImprovingSpeculative2024]
- The paper has no dedicated limitations section.
